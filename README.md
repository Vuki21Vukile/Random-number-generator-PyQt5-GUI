# Random-number-generator-PyQt5-GUI
A Python random number generator small project that is made with PyQt5 graphical interface. This is my first project with PyQt5.

This is my first small GUI app, it is simple and it does not use any complex code.
I was just having fun, learning PyQt5 and getting into GUI-s.
Program has labels, button, and some styles on text, and some colors to it.
It can be very easily upgraded to a more complex app, i can add images, sounds, some user inputs and soo on. But this is just a first look on GUI, i know its not much but its meaning a lot to me :)
